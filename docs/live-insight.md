# 实时洞察

盯盘里的第三页，地址 `/watch/insight`。它看的是**还在变化或刚刚按间隔存下来的公开行情和资金**，用来补情绪复盘（收盘口径）覆盖不到的盘中过程。情绪复盘、竞价六个时点、交易日志都不走这里。

关闭：启动前设置 `VA_LIVE_INSIGHT=0`（也认 `false` / `off` / `no`）。关掉之后定时采集和页面上的「再采一张」都不再联网，页面只说明已关闭。

## 现有能力里它不替代的部分

- **实时动态** `/watch`：持仓、自选、昨日梯队、大票、成交额前十，以及 3 分钟急拉急跌、封板开板。持仓仍不发给 AI。
- **竞价与盘中** `/watch/intraday`：09:25 / 09:35 / 10:00 / 11:30 / 14:00 / 15:00 六张快照。过点不补。
- **情绪复盘**：`cn_shortline_emotion`、`cn_shortline_daily`、`cn_shortline_facts` 等收盘口径。实时洞察不调用它们，也不把它们的结果贴成「此刻」。

## 数据从哪来

采集只走仓库里已经登记的公开端点，默认 `consistency: fresh`，避免把昨天的缓存当成现在。

| 用途 | 端点 | 口径和限制 |
|---|---|---|
| 三所涨跌家数、涨跌分布 | `em_market_breadth` | 只有当日快照。分布合计和三所家数不是同一套，页面不互相凑。上游日期不是采集日时标出来 |
| 行业 / 概念资金 | `em_board_fund_flow` `period=today` | 东财**主力净额**，元，今日累计。只留净额排序前 40。掉出名单没有后续点，不当成归零 |
| 东财失败时的资金备源 | `sina_board_flow` | 新浪「流入 − 流出」。板块分类不同，**不能**和东财净额比大小或接曲线 |
| 行业涨跌家数、领涨 | `em_industry_comparison` | 补在东财行业行上。没有的格子留空 |
| 涨停结构 | `em_zt_pool` | 只使用证据日期等于采集日的池。空池按缺失，不写成 0 家 |
| 指数 | `tx_quotes_batch` | 上证、深证成指、创业板指。行情时间不是采集日就标「非今日」 |
| 盘中情绪 | `cn_shortline_live` | 上游在非交易日、开盘前、集合竞价会直接说明没有。页面照抄原因，不用上一交易日 |
| 分钟资金样本 | `em_turnover_rank` + `em_fund_flow_minute` | 成交额靠前、涨跌幅绝对值在 0.3%–4%、且不在当次涨停池里的最多 6 只。东财主力净额是**当日累计**。ETF 常常没有 |
| 龙头的概念 | `em_concept_blocks` | 只给涨停广度最高的最多 3 个行业的龙头。对得上的概念才和概念资金行一起看 |

没有购买行情，也没有另外部署采集器。取数失败、超时、限流写成缺口，保留上一张成功的快照，不用 0 填充。

## 什么时候采集

北京时间，跟盯盘同一套钟。

- 周末、午休（11:30–13:00）、开盘前、集合竞价、收盘集合竞价：不取行情。午休即使点刷新也不取。
- 法定假日：连续竞价和收盘窗口会先查 `fetch_trade_calendar`。不是交易日就不取涨停池和资金，避免东财把上一个交易日的池子回过来。日历结果：说得清的缓存 30 分钟，没取到的 60 秒后再试。
- 上午、下午连续竞价：距上一张不足 120 秒就节流。同一数据目录同时只有一轮（单飞），多个浏览器窗口不会叠请求。
- 15:00–15:20：若还没有 15:00 之后的那张，自动存一张收盘累计。过了 15:20 自动停。手动刷新可以再补一张，页面按「已收盘」展示，不叫正在进行的盘中。
- 程序没开的时段没有快照，过后不补。

落盘：`<数据目录>/live-insight/<YYYY-MM-DD>/snapshots.jsonl`，外加 `live-insight/last-attempt.json`。不进台账，不改 `shortline/intraday`。读页面（GET）不写盘；写入只发生在 POST `action=capture` 和定时拍子里。

选日期看的是那一天已经存下的记录，文案写明「不是当前实时」。

## 算法在判断什么

阈值都在 `orchestrator/src/finance/live_insight/analyze.ts`，测试用同一套。

**资金变化。** 和 2–40 分钟内、同一供应商的上一张比。净额变化达到 1.5 亿元，或名次至少跳 12 位且变化达到 0.5 亿元，才列入「可解释的资金变化」。说明里写两张的时刻、净额、涨跌幅，以及净额和涨跌是同向、背离还是涨跌几乎没动。跨午休、口径切换、间隔太长或太短：不标，并写原因。可靠性：两边涨跌幅都有且间隔 5–20 分钟为高，否则中或低。

**疑似低波动净流入。** 只用连续竞价里的点（去掉午休）。分钟序列至少 20 个点、采集样本至少 3 个点，跨度至少 15 分钟；最后一点净额为正且高于起点；上升步数不少于 55%；最大一步不超过整段抬升的 60%；当日涨跌幅绝对值不超过 4%。缺涨跌幅、点不够、最后一点比当前钟点早 15 分钟以上、或正在午休：不标。采集样本（没有分钟线、只有每 2 分钟一个累计值）可靠性最高只到低。文案固定写明：这是东财主力净额累计的统计形态，不是龙虎榜机构席位，也不是股东或基金持仓。

**热点扩散。** 行业内板位最高、首封更早的为龙头。两张间隔 2–25 分钟、不跨午休的涨停池里，原龙头还在，同行业只数至少多 2 且新出现至少 2 只，才叫扩散。相关概念必须出现在这只龙头的东财概念归属里，再去对概念资金行。没有概念归属时信号仍可出现，可靠性降为低。只有一张池、池子日期不对、或空池：只说明结构或缺失，不叫扩散，也不写成 0 家涨停。

这些句子描述已经发生的公开数据。页面不给买卖、目标价或择时。

## 刷新

页面开着约每 20 秒读一次已存快照（休市 60 秒）。后端若标记 `capture_due`，页面再请求采集；服务端仍受 120 秒节流和单飞约束。切到后台就停。失败会退避，上一份结果留着，并写明这次没取到。

涨停观察池不走这个 2 分钟节拍。它在收盘任务里入池，行情按跟踪名单分批更新，见 [limit-watch.md](limit-watch.md)。

## 还没有的

- 没有逐笔成交，指数和资金都是供应商快照。
- 没有全市场每一只的分钟资金，只有上面那几只样本。
- 概念板块没有涨跌家数（行业对比接口不覆盖概念）。
- 东财四档（超大、大、中、小）净额没有进当前证据行，解释只用主力净额和涨跌幅。
- 2026-11-07 为周六，此功能没有真实盘中对照。
